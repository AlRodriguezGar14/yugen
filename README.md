# Yugen

Context-first language learning from the text around you; Japanese is the
first language pack.

The public mobile prototype lives in `mobile/` and uses Expo, React Native,
TypeScript, and pnpm.

```bash
pnpm --dir mobile install
pnpm --dir mobile start
```

See the [Expo documentation](https://docs.expo.dev/) for general development
build and device instructions. Third-party attribution is in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

The product is under active development.
